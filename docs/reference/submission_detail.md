# The full report for one file in a submission check

The full report for one file in a submission check

## Usage

``` r
submission_detail(x, file)
```

## Arguments

- x:

  A `figspec_submission` object.

- file:

  File name, as shown in the submission table.

## Value

The `figspec_report` for that file.
